# 网页预览

手机可从虚拟键盘的设置菜单进入“网页预览”，平板 / PC 可使用顶部的“网页预览”按钮。在 HiSH 内访问 Web 服务时，应用可保持在前台。

例如：配置模拟器端口 `3080` → 主机端口 `8000`，保存并重启模拟器，在 Linux 中启动监听 `0.0.0.0:3080` 的服务，然后在预览页面输入 `http://127.0.0.1:8000`。页面支持输入地址、刷新、网页历史返回及映射端口快捷选择。

映射端口菜单显示当前模拟器配置中未被启动阶段跳过的主机端口，不检测该端口是否实际运行 HTTP 服务。修改端口映射后需重启模拟器再访问。

预览仅支持 HTTP / HTTPS，没有终端页面使用的原生 JavaScript 桥，也不自动打开其他应用、下载文件或跳过证书错误。打开网页仍受该服务的登录与认证要求约束。
