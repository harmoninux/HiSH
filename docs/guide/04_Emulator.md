# 模拟器管理

HiSH 支持创建多个模拟器实例，方便用户实现镜像制作、环境隔离等操作。同一时刻，用户可以选择任一实例运行。

在主界面下方选择“模拟器管理”即可进入“模拟器管理界面”，该界面展示了当前 HiSH 中的模拟器实例，并提供了 模拟器管理、镜像管理、共享文件夹管理
功能。

## 模拟器管理

模拟器管理界中，您可以点击标题栏右侧的“添加”按钮（PC则在列表下方），进入“编辑模拟器”界面，完成模拟器的基本配置后，即可点击“完成”完成模拟器创建。

在创建模拟器的界面中，可以设置：

* CPU核数：指定CPU核数
* 内存大小：指定内存大小
* 系统镜像：选择HiSH中已有的镜像创建模拟器
* 端口映射：将对主机端口的访问转发到模拟器端口中
* 只读共享文件夹
* init

在“模拟器管理”列表中，可以看到当前正在运行的模拟器实例，也可以其它点击卡片中的 “运行”
按钮启动其它模拟器，也可以直接将常用的模拟器实例设置为“默认启动”，即在HiSH启动时自动运行。

模拟器管理中还可以支持：

* 删除：删除模拟器实例及其对应的数据
* 复制：基于当前模拟器的配置和镜像复制一个新的模拟器实例
* 导出：保存将当前模拟器的文件系统镜像，用于后续创建新的模拟器时作为模板
* 修改：修改模拟器的运行设置，通常需要重启后才可生效

## 从本机访问 Linux 中的 Web 服务

HiSH 已支持 TCP 端口映射，无需桥接网络。例如服务使用模拟器端口 `3080`，可在模拟器配置中添加“模拟器端口 `3080` → 主机端口 `8000`”。两端端口都必须是 `1` 至 `65535` 的整数。

1. 在 Linux 中让服务监听 `0.0.0.0:3080`。仅监听 Linux 自身的 `127.0.0.1` 时，来自 QEMU 虚拟网络的转发连接无法访问该服务。
2. 保存映射并重新启动该模拟器。修改配置不会为已经运行的 QEMU 动态增加映射。
3. 在运行 HiSH 的设备上访问 `http://127.0.0.1:8000`。`10.0.2.15` 是模拟器的内部地址，不是主机浏览器的访问地址。

可以先用简单服务排除业务应用本身的问题：

```sh
# 在 Linux 中执行；需先安装 python3。
python3 -m http.server 3080 --bind 0.0.0.0
```

若仍无法访问：

* 先在 Linux 中访问 `http://127.0.0.1:3080`，确认服务已启动。
* 查看启动时的端口占用提示。被其他程序占用的主机端口会跳过映射；换一个主机端口后重启模拟器。
* 检查两端端口是否填反，以及服务是否仍只监听 Linux 的回环地址。
* 改用 HTTPS 服务时，同时检查服务证书与访问地址是否匹配。

当前映射的 QEMU 参数使用 `hostfwd=tcp::主机端口-:模拟器端口`，没有限定主机监听地址。局域网可达性受系统与网络环境影响；仅供本机使用或包含私有数据的服务，应设置应用层认证，不要把端口映射视为访问控制。
